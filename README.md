
# Online Retail Business Performance & Sales Analysis

## Project Overview
This project was completed as part of a Data Analytics Job Simulation through Forage.

The objective was to analyse online retail transactions and develop a Power BI dashboard to generate business insights and support management decisions.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Project Objectives
1. Analyse monthly revenue trends for 2011.
2. Identify the top 10 revenue-generating countries, excluding the UK.
3. Identify the top 10 customers by revenue.
4. Visualise geographical product demand to identify potential expansion opportunities.

## Data Preparation
- Imported the retail dataset from Excel.
- Investigated missing values and data types.
- Examined negative quantities and cancelled transactions.
- Created revenue calculations using DAX.

## Dashboard Features
- Monthly Revenue Analysis
- Top 10 Countries by Revenue
- Top 10 Customers by Revenue
- Geographical Product Demand Analysis
